原始传奇逆向工坊

Mir2 Reverse Web · 资源提取 / 数据解析

提取总览

这是一个参考 Web 页游《原始传奇》的逆向工坊：从线上 CDN 拉取资源与配置，并在本地解析 / 预览 / 导出。选择一种资源开始：

🗺
提取地图资源
下载地图数据包（.dat），解析每张地图的可走性 / 遮挡 / 安全区，预览真实瓦片地图与小地图，并导出 PNG + JSON。
🎞
提取所有图集
从 manifest 总索引解析全部图集 / UI 资源，按 CDN 规则下载到本地（含纹理图集 JSON 元信息）。
📋
提取配置表
下载 0config 配置，把每张表（map / global / level …）映射为 C# 类，并导出 JSON 数据。
资源来源：CDN 根 https://cdn.yscq-wy.yscq.com/fugu_20201203  ｜  配置版本 10.25341.1
配置拼接规则（同游戏 JS onloadCfgAgain）：数据服务器根 + "0config" + 版本号 + ".json?v=" + 版本号

「提取选中地图资源」为每张选中的地图在输出目录下创建一个以「地图名_id」命名的文件夹，内含：
① tiles/：真实地图瓦片（zipmap/{img}/{n}.jpg，512×256，这才是真实地图画面）
② map_<id>_real.png：瓦片拼接总览图（勾选“生成拼接总览图”时）
③ map_<id>.json：解析出的结构化地图数据（每格可走/遮挡/安全区标志，可合并进游戏客户端）
④ minimap.png：小地图（优先取 assets/resource/minimap/{img}.jpg 独立整图；取不到再回退 minimaps 图集 {img}_png 帧，仍无则 43005_png 默认帧）。
