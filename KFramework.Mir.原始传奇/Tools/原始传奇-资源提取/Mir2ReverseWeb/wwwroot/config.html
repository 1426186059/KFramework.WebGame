拼法与游戏主程序 JS 的 onloadCfgAgain 完全一致：数据服务器地址 + "0config" + 版本号 + ".json?v=" + 版本号。
该文件顶层每个键（map / global / level / conditions / compose …）就是一张「配置表」。
每张表可提取为两类产物：① <表名>Config.cs（由字段自动推断并映射 JS 对象到 C# 类）；② <表名>.json（保持原始形态的数据，按 URL 下载提取）。
