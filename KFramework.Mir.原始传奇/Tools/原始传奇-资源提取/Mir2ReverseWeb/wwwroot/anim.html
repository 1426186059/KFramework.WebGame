资源版本映射（resourceVersion.json）

该文件即原版 JS 的 cm.version：全量「资源名 → 版本号」映射，含所有角色/NPC/怪物动画精灵表条目（model/{模型号}/{sourceId}.png/.json）。先加载它，解析出全部模型号后再决定导出哪些。

每个模型号 = 一个角色/NPC/怪物/武器 的动画集合（含其所有动作×8方向帧表）
导出范围与输出
留空 = 导出全部（resourceVersion.json 里的 4774 个模型号，无需抄下面清单）
默认 60（动作号超过此值不再尝试；按需下调可减少请求量。帧按 sourceId=1000×模型号+10×动作+方向 枚举，命中才下载、404 自动跳过） 
动画 URL 拼装（逆向自 ResUrl / ActionLoader）：
  {CdnBase}/assets/resource/{版本号}/model/{模型号}/{sourceId}.png?ver={ResourceVersion}
  sourceId = 1000×模型号 + 10×动作 + 方向（0~7，5~7 为镜像）
每个 (模型号, 动作, 方向) → 一张精灵表 png + 一份帧描述 json（frames[a]={x,y,w,h}，同 UI 图集结构）。
导出即把这张「资源名→版本」表里的所有 model/ 条目按上述规则下载到本地，复刻版可直接按 ResUrl 加载播放。
