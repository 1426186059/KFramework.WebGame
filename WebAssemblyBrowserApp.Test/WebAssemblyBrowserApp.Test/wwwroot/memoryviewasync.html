MemoryView 异步内存稳定性

验证「异步（await）期间 MemoryView 的内存会不会变」：C# 把已知内容（i*7）的 byte[64] 交给 JS 存下，再（实验组）真等 3 秒 + 强制 GC（模拟真实 await 把控制权交还事件循环的时间窗）， 让 JS 把视图读回来，C# 比对字节。对比 unpinned(Span) 与 pinned(ArraySegment) 两种； 另加「不 GC 立即读」对照，用来区分是「调用一返回就释放」还是「被 GC 搬走才失效」。实测结论： unpinned 在调用结束即抛 ObjectDisposedException（活不过一次调用，更别提跨 await）， pinned 则钉住不变。进入本页会自动开始运行。
