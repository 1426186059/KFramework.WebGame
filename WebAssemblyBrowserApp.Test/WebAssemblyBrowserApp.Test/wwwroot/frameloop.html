帧循环：一趟推 vs 两趟拉

模拟引擎宿主那行 host.Frame(timestamp, gameFrameData.takeFrameData()) 的取舍： A 一趟推（JS→C# 顺带把一帧的输入事件字节流带进来 —— 这个方向只能带 byte[]）、 B 两趟拉（先推帧不带数据，C# 再回头调 JS，用 MemoryView 零拷贝直写自己的缓冲）。 两条路线都由 JS 侧整体计时 —— 一次调用 = 一帧的工作量，所以「ns/操作」就是 ns/帧。 载荷按每帧 0 / 16 / 256 / 1024 字节分档，其中 0 B = 这一帧没有输入，用来单独量"多一趟"要付多少。 进入本页会自动开始运行。
