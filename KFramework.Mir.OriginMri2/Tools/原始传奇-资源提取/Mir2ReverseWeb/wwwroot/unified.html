原始传奇逆向工坊

Mir2 Reverse Web · 资源提取 / 数据解析

按配置表提取资源（统一模式）

一次扫描全部 0~5 配置表：所有 model 字段（怪物 / NPC / 称号 / 特效 / 物品外观…）导为 model 帧，物品表第 19 列导为物品图标，技能表 icon 导为技能图标。三类资源分别落到下方各自目录，点一个按钮全部提取。首次会自动加载配置表（6 个分片）。

所有 model 帧落这里：{目录}\{模型号}\{sourceId}.png|json（去版本号，与客户端同相对路径）。

item 表第 19 列图标 ID → {目录}\{iconId}.png（相对路径 assets/resource/icon/tool，无 model 段）。

skill 表 icon 字段 → {目录}\{iconId}.png（相对路径 assets/resource/icon/skills）。

高级选项（动作枚举上界等）

默认 60：modelInfo 未登记动作的模型才用它兜底枚举，按需下调减少请求量。

相对路径规则（逆向自 ResUrl / ItemIconPath / SkillIconPath，均去版本号段）：
  model 帧：   assets/resource/model/{模型号}/{sourceId}.png
  sourceId = 1000×模型号 + 10×动作 + 方向（0~7，5~7 为镜像，按 modelInfo.totaldir 只取真实朝向）
  物品图标：   assets/resource/icon/tool/{iconId}.png
  技能图标：   assets/resource/icon/skills/{iconId}.png
落地到 Mir2Res 对应相对路径后，即可被本地资源服务器(:5080)按同相对路径加载。
