按配置表提取资源（统一模式）

不再依赖 resourceVersion 清单：直接从原版配置表（怪物 / NPC / 称号 / 技能特效 / 物品…）解析出资源条目（模型号 + 名字），选中即可导出。技能特效已按 type 标注施法 / 命中 / 飞弹；物品外观为实验性（按 Looks 列）。首次使用会自动加载配置表（6 个分片，约数 MB）。

高级选项（动作枚举上界等）

默认 60（动作号超过此值不再尝试；按需下调可减少请求量）。帧按 sourceId=1000×模型号+10×动作+方向 枚举，命中才下载、404 自动跳过。

动画 URL 拼装（逆向自 ResUrl / ActionLoader）：
  {CdnBase}/assets/resource/{版本号}/model/{模型号}/{sourceId}.png?ver={ResourceVersion}
  sourceId = 1000×模型号 + 10×动作 + 方向（0~7，5~7 为镜像）
每个 (模型号, 动作, 方向) → 一张精灵表 png + 一份帧描述 json（frames[a]={x,y,w,h}，同 UI 图集结构）。
导出走有/无版本号双路径：在 resourceVersion 里的模型用版本段，不在的（如多数技能特效 L1）走无版本号路径，文件均在 CDN 上。
