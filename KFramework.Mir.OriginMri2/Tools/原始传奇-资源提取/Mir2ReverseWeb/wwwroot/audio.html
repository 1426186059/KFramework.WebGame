Mir2 Reverse Web · 音频资源提取

配置来源（用于收集音频 id）
CDN 没有音频清单，音频按 assets/resource/audio/{id}.mp3 独立寻址。本页从 0~5 全部配置分片递归扫描 sound / file 等字段，收集游戏实际引用的所有音频 id（含技能音效 skillEffects、地图 BGM soundnormal 等）。
输出目录约定：默认落到 Mir2Res/assets/resource/audio/。Mir2Res 是将来的远程资源根，目录结构与原始传奇 CDN 的相对路径一致、仅去掉版本号段（如 model 资源 CDN 为 assets/resource/{版本号}/model/...，Mir2Res 为 assets/resource/model/...）；音频本无版本号段，故路径与 CDN 完全相同。:5080 资源服务器把 /assets/ 映射到该目录，客户端按同相对路径加载，无需回源 CDN。
