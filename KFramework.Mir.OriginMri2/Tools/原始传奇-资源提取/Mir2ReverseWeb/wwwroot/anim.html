Mir2 Reverse Web · 资源提取 / 数据解析

资源版本映射（resourceVersion.json）

该文件即原版 JS 的 cm.version：全量「资源名 → 版本号」映射，含所有角色/NPC/怪物动画精灵表条目（model/{模型号}/{sourceId}.png/.json）。先加载它，解析出全部模型号后再决定导出哪些。

序号 模型号 动画名字 资源版本 操作

每个模型号 = 一个角色/NPC/怪物/武器等 的动画集合（含其所有动作×8方向帧表）。「动画名字」全部逆向自原版客户端配置分片（{n}config）：怪物/NPC 表（model 字段）、物品表（外观号 Looks，第20列主外观＋第17列次级外观，按 Type 区分 武器/衣服/翅膀/装备…）、称号表（model 可拆成对）、技能/Buff/成就/星盘等表的数字 icon 字段；技能特效按 skillEffects（键=技能id×100+等级，可回链 skill 表名字）→ effect 表（id→model 精灵号）命名成「特效·雷电术(Lv5)」这类；其余纯特效按 effect 表回链 Buff 名或归类「特效-模型号」。**特效精灵以 effect 表的 model 字段为准，优先级高于技能/UI 图标的 icon 引用**——那些 icon 是图集索引而非 model 精灵号（如一个精灵不可能既是“雷电术Lv5特效”又是“地狱火技能图标”，后者是误算），故特效名会覆盖之，但不覆盖真实怪/NPC/物品/称号精灵。当前版本快照约 4200/4774（≈89%）能直出名，剩下约 11% 是 UI 图标类（配置里以字符串资源名引用、非数字模型号）等无统一名字的，显示「—」。「资源版本」是该模型各自当前的版本号（不同模型版本不同，正是你看到的 3.x / 10.x 并存的原因）。

导出范围与输出
高级选项（动作枚举上界等）

默认 60（动作号超过此值不再尝试；按需下调可减少请求量）。帧按 sourceId=1000×模型号+10×动作+方向 枚举，命中才下载、404 自动跳过。导出范围由上方条目勾选决定：勾选部分=仅导出勾选；全不选=导出全部（resourceVersion.json 里的全部模型号）。

动画 URL 拼装（逆向自 ResUrl / ActionLoader）：
  {CdnBase}/assets/resource/{版本号}/model/{模型号}/{sourceId}.png?ver={ResourceVersion}
  sourceId = 1000×模型号 + 10×动作 + 方向（0~7，5~7 为镜像）
每个 (模型号, 动作, 方向) → 一张精灵表 png + 一份帧描述 json（frames[a]={x,y,w,h}，同 UI 图集结构）。
导出即把这张「资源名→版本」表里的所有 model/ 条目按上述规则下载到本地，复刻版可直接按 ResUrl 加载播放。
